# 公开内容与隐私检查

公开内容限于原创插件/工具源码、模拟测试、协议说明、已解释的地址/命令和按字段白名单整理的 RPM 样本。Git 作者使用 GitHub 公开用户名与 noreply 邮箱。

本次发布前检查源码、文档、Git 暂存区和 Release 文件中的个人绝对路径、凭据形式、设备唯一标识、私有网络地址、邮箱及未预期二进制。原有本机安装路径改为显式参数，Desktop Runtime 路径由运行环境解析。Release DLL 不附带 PDB。

未上传：

- SPI/BIOS/EC 原始镜像、UEFI NVRAM 和完整反汇编导出。
- SMBIOS UUID、序列号、MAC 地址、设备/账号清单及完整 ACPI 转储。
- GitHub 登录文件、令牌、私钥、下载会话或验证码信息。
- 厂商控制中心、第三方驱动/DLL、反编译的厂商源码。
- 本机日志、异常堆栈、进程 ID、配置缓存或未清理的测试输出。

仓库 `.gitignore` 排除上述常见原始文件及运行时结果；发布只从显式整理的文件列表提交。型号、通用固件版本、协议地址、公共项目链接和指定驱动的 SHA256 属于复现所需的信息，予以保留。

运行脚本会在本地产生结果文件，异常文本可能包含路径。提交 issue 时也应自行检查，不要上传完整固件或未经清理的系统日志。
